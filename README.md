# cursor-project

小红书美妆热点前十看板，给上海上门化妆师毛毛看观察窗口约 2026-10-15～10-30 的十条选题。

页面是单个静态文件 `index.html`，数据写在页面里。不需要安装依赖，也不需要构建。

## 怎么打开

在仓库根目录用浏览器直接打开 `index.html`：

- macOS：`open index.html`
- Linux：`xdg-open index.html`
- Windows：双击 `index.html`

或者在仓库根目录起一个本地静态服务：

```bash
python3 -m http.server 8765
```

然后在浏览器打开 <http://127.0.0.1:8765/> 。

## 页面上有什么

- 适合度筛选：全部 / 适合 / 一般 / 不太贴。筛选同时作用于条形图和选题表。
- 横向条形图：长度是排序权重（第 1 名 = 10，第 10 名 = 1），颜色是适合度。热度线索单位不一样，图上没有热度轴。筛选不会把剩下的条重新拉满。
- 十条选题表：名称、是什么、热度线索、适合度、给账号的建议。
- 本周三条笔记脚本：三条占位，标题带上海和场景，正文是「脚本撰写中」。
